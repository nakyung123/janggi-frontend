# 화면

- 화면 규칙(색·치수·컴포넌트)은 `DESIGN.md` 에 있다.
- 폰 폭 **320 · 360 · 375 · 390** 에서 **대국 탭과 기보 탭 둘 다** 본다. 가로 스크롤이 생기지 않아야 한다. 사용자의 폰이 320 이다.
- 로컬 WebKit + `http://localhost` 에서는 엔진 워커가 COEP 에 막힌다. Playwright WebKit 의 알려진 현상이고 우리 문제가 아니다. 배포본(HTTPS)에서는 뜬다.
- 엔진을 기다리는 확인처럼 긴 대기가 필요하면 먼저 말하고 기다린다.
- 쓰는 사람은 장기를 두러 온 사람이다. `npm`, `SharedArrayBuffer`, 영어 예외 메시지처럼 내부 사정이 섞인 말을 화면에 띄우지 않는다.
