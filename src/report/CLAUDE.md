# src/report

**앱이 망가졌을 때 밖으로 알리는 자리.** 저장소 전체 규칙은 뿌리의 `CLAUDE.md` 에 있다.

| 파일 | 하는 일 |
| --- | --- |
| `errors.ts` | 무슨 일이든 `{code, message, detail}` 로 바꾼다. **영어가 화면에 새지 않게 막는 곳** |
| `feedback.tsx` | 기기 이름 붙이기(브라우저 · OS · 인앱)와 제보 창구 |
| `events.ts` | 측정. 바깥으로 내보내는 자리는 **`send()` 하나뿐** |

## 오류가 흐르는 길

```
무슨 일이 터진다
  -> noteTrouble()   errors.ts 가 {code, message, detail} 로 만든다
  -> 화면   message   한국어. "무엇을 하면 되는지"
  -> 서버   detail    영어 원문. 겁만 주고 아무것도 안 알려줘서 화면엔 안 띄운다
  -> 둘 다  code      E-XXXX. 제보와 서버 기록을 잇는 열쇠
```

- **영어는 화면에 새지 않는다.** 한글이 없는 오류는 전부
  `알 수 없는 오류입니다. (E-XXXX)` 로 바뀐다.
- **"무엇이" 는 화면이, "어떻게 하면" 은 오류가 맡는다.** 이 선을 한 번 지웠다가
  `알 수 없는 오류입니다` 만 남아 **무엇이 실패했는지 알 수 없게** 됐다.
- **`code` 는 되돌릴 수 없는 해시다.** 그것만으로는 원문을 모르니 `engine_failed`
  에 `detail` 을 같이 보낸다. 사람이 제보에 `E-7F3A` 를 적어 보내면 **그 코드로
  서버 기록을 찾는다.**

## 측정

- **이벤트를 만드는 코드는 두 번 쓰지 않는다.** 보내는 자리는 `send()` 하나고,
  서버가 생기면 **거기만** `navigator.sendBeacon` 으로 바뀐다.
- **`track()` 은 무슨 일이 생겨도 삼킨다.** 저장소에서 "조용히 넘어가지 않는다" 의
  유일한 예외다 - 측정 때문에 앱이 멈추면 안 된다.
- **삼키는 쪽이 조용히 깨진다.** 2026-10-13 에 `isolated: crossOriginIsolated` 가
  사파리 15.2 이전에서 `ReferenceError` 를 내는 것을 찾았다. `track()` 이 그것을 삼켜
  **그 기기에서는 측정이 통째로 안 갔다.** 하필 엔진이 못 뜨는 기기라 가장 알고 싶은
  사람이 안 보였다. **전역은 `typeof` 로 확인하고, 없으면 거짓이 아니라 `null` 이다.**
- **보내는 시점이 숫자를 정한다.** `NOW` 에 든 이름은 즉시, 나머지는 쪽이 가려질 때
  묶어서 간다. 묶음은 못 잡고 사라진 사람을 놓친다 - 2026-10-11 에 Vercel 은 25번
  열렸다는데 우리는 13개였다. **즉시 보낼 때 `flush()` 를 부르지 않는다** - 대기열을
  통째로 비워서, 유실률을 재려고 묶음으로 남긴 대조군이 같이 나간다.
- **격리 여부 · 코어 · 메모리는 공통에 둔다.** 실패한 쪽에만 있으면 분모가 없어서
  "4GB 기기가 잘 깨지나" 에 답할 수 없다.
- **방문 번호(`sid`)는 모듈 변수다.** `sessionStorage` 에 두면 새로고침해도 남아
  사람을 이어 붙이게 된다.

## 만들기 전에 짚을 일곱

| | |
| --- | --- |
| **아무것도 없을 때** | 0건 · `null` · 빈 배열. **표본 0 을 0% 로 쓰지 않는다** |
| **그 기능이 없을 때** | `deviceMemory` 는 크로미움만, `crossOriginIsolated` 는 헤더가 있어야 |
| **앱 안 브라우저** | 카카오톡 · 인스타그램. **UA 모양이 다르다** (아이폰은 `Safari` 토큰이 빠진다) |
| **느릴 때 · 끊길 때** | 6MB 를 받다 끊기면? 보내는 중에 창이 닫히면? |
| **두 번 눌렀을 때** | 같은 걸 또 눌러도 꼬이지 않나 |
| **320 폭** | 진단 줄이 한 줄에 들어가나 |
| **떠나는 순간** | `visibilitychange` · `pagehide`. **`unload` 는 폰에서 안 불린다** |

## 실패를 흉내 내 본다

성공만 보고 끝내지 않는다. 여기서 실제로 쓰는 방법들이다.

- 격리 헤더 없는 서버로 `dist/` 를 띄우면 **단일 스레드 엔진**이 뜬다(E2E 의 "격리 없음" 프로젝트가 이렇게 돈다).
- Playwright 로 `**/engine/**` 을 막으면 **엔진 받기 실패** 화면이 나온다.
- UA 를 바꾸면 인앱 브라우저가 된다. 봇 거르개 때문에 **평범한 UA 로 바꿔야**
  이벤트가 찍힌다.

**아직 못 흉내 낸 것** - 받다가 중간에 끊기는 실패. 그래서 `engine_failed` 의
`stage` · `loaded` · `total` 은 배선만 해 두고 **값을 본 적이 없다.**
